# VCO-Converting-DC-Signals-to-Triangular-waves
This project implements an analog Voltage Controlled Oscillator (VCO) where a DC control voltage determines the oscillation frequency of a triangular waveform.
The system converts a DC input signal → square wave → triangular oscillation using operational amplifier based circuits. The frequency of oscillation is directly proportional to the control voltage, while the peak-to-peak amplitude of the triangular waveform remains constant.

A PID controller is used to regulate the system and maintain stable frequency response against disturbances or parameter variations.

The project explores multiple circuit techniques including MOSFET switching, diode switching, differentiation, Schmitt triggers, and op-amp based control systems, making it a comprehensive study of analog oscillator design and feedback control.
